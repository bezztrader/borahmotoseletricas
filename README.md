# Borah Motos Elétricas · Freguesia

Site da Borah Motos Elétricas, unidade Freguesia (Jacarepaguá – RJ). "E aí, Borah de elétrica?"

Next.js (App Router) + Tailwind CSS + Motion + Lenis.

```bash
npm install
npm run dev
```

- Especificações dos modelos e fotos: `src/lib/site.ts` (campos `[preencher]`, `photo`).
- Constantes da calculadora de economia: `src/lib/economia.ts`.
- Antes do deploy, defina `NEXT_PUBLIC_SITE_URL` com o domínio real.
